# Version 0.1.0

Initial review version. The default local topology captures WAL into Redpanda and materializes current payment state in a separate PostgreSQL instance. Optional reconciliation, backfill, and analytics services use the same Compose network.

Use the [runbook](../RUNBOOK.md) for startup and recovery and [evidence](../EVIDENCE.md) for verification status. Existing data volumes assume the v0.1.0 schema.
